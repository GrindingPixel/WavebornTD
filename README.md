# Waveborn TD – Roblox Anime Tower Defense

Projektstruktur basierend auf Rojo + GitHub.

## Ordnerstruktur
- `src/client/`: Lokale Client-Skripte (UI-Handler, Input)
- `src/server/`: Gameplay-Logik, DataStore, Systeme
- `src/shared/`: Gemeinsam verwendete Module
- `src/Modules/`: Debounce, PanelManager, Configs etc.
- `src/UI/`: GUIs (BattlepassGui, ShopGui etc.)
